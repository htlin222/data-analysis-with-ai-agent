# demo — 學員練習資料夾

跟著課程做一次。這個資料夾裡有你需要的全部素材：

| 你有的 | 內容 |
|---|---|
| `raw/cohort.csv` | 100 人的存活分析資料，與課程投影片、錄影中的完全同一份 |
| `raw/README.txt` | 資料說明，含兩項「不是錯誤、但必須處理」的性質 |
| `PROMPTS.md` | 全部提示詞，可直接複製貼上 |

`scripts/` `output/` `figs/` `docs/` **不在這裡**——那正是你等一下要產生的東西。
git 不追蹤它們，所以你怎麼弄壞都沒關係，刪掉重跑就好。

---

## 開始之前

在 Codespace 的終端機裡，先把自己放到正確的位置：

```bash
cd demo
pwd          # 結尾應該是 /demo
ls           # 應該看到 raw 和 PROMPTS.md
```

**接下來整堂課，你都待在 `demo/` 裡面。** `claude` 在哪裡啟動，它就只看得到那裡。
在專案根目錄啟動的話，它會看到講師的 `scripts/`，直接照抄一份給你——那你就沒東西可練了。

把原始資料設成唯讀。這是這門課唯一的硬規定：

```bash
chmod a-w raw/cohort.csv
```

Codespace 已經內建 `claude`、R 與課程用的七個套件，你不需要裝任何東西——
開機時已經驗收過一次，失敗的話你會在建置紀錄裡看到 `FAIL`。要自己再確認一次：

```bash
bash ../.devcontainer/verify.sh
```

**第一次打 `claude` 需要登入**，照畫面走完就好，之後不用再登。

在自己的電腦上做這份練習、而 `Rscript --version` 沒有反應的話，用 `PROMPTS.md` 的 **P0** 讓 Claude 幫你裝。

## 流程

七個指令、六個回合。每一步的提示詞在 `PROMPTS.md`，這裡只講會發生什麼事。

| 步驟 | 你做的事 | 產出 |
|---|---|---|
| 1 | 七個終端機指令：`pwd` `ls` `cd` `head` `tail` `cat` `mkdir` | 資料夾架子 |
| 2 | 啟動 `claude`，用 **P1 P2** 讓它先看、先講，不要動手 | 無（刻意的） |
| 3 | **P3**：逼它把三個決定講出來；**P4**：你決定完，才讓它寫 | `scripts/01_clean.R` `docs/cleaning_log.md` `output/cohort_clean.csv` |
| 4 | **P6 P7**：描述性統計與 Table 1 | `scripts/02_describe.R` `output/table1.html` |
| 5 | **P8–P12**：KM、Cox、次族群 | `scripts/03_survival.R` `figs/*.png` `output/cox.csv` |
| 6 | 把 `output/` `figs/` 全部刪掉，再長回來 | 一個 `Makefile` |

第 3 步是全課核心。它會在你沒交代的地方自己挑一個常見做法，然後若無其事地繼續往下做——
所以要在它動手之前，先把三個決定講出來。

## 對答案

跑完之後，把你的數字跟這裡對。**不一樣不代表你錯了**，但你要說得出來哪一個決定造成了差別。

| 項目 | 應該是 |
|---|---|
| 讀入 | 100 列 × 7 欄 |
| `age` 缺失 | 4 筆（不插補） |
| 死亡 / 設限 | 69 / 31，其中 25 筆 `time = 36` 為行政設限 |
| 清洗後 | 100 列 × 9 欄 |
| Table 1 的 N | 年齡那一列是 **96**，其他列是 100 |
| 中位追蹤（reverse KM） | 36.0 月 |
| 中位存活 | 17.5 月 |
| KM by stage | advanced 10.6 月、early 28.3 月，log-rank p = 0.0004 |
| KM by treatment | 17.5 月、17.7 月，log-rank p = 0.83 |
| Cox 實際樣本 | **96 人 66 events**（不是 100 / 69），EPV 16.5 |
| Cox：stage early | HR 0.404（0.24–0.67） |
| 次族群 | 組內 p = 0.0014 與 0.107，**interaction p = 0.246** |

最後三列是這堂課後半要判讀的東西：

- **治療組沒有差別**（p = 0.83）。這不等於兩種藥一樣好，只是這 100 個人看不出差別。
- **Cox 少了 4 個人**，而且 R 不會警告你。所以腳本要自己印出模型實際的 n。
- **次族群的組間對比是雜訊**：兩組的 p 一個顯著一個不顯著，但 interaction p = 0.246——
  該看的是後者。切點又是事後才決定的，所以這段只能算探索性。

## 三條硬規定

寫進你的提示詞裡，AI 才會遵守：

| 規定 | 為什麼 |
|---|---|
| 不改 `raw/` | 原始資料被改過，就沒有東西可以對照 |
| 路徑用 `here::here()`，不用 `setwd()` | `setwd()` 換一台電腦就死 |
| 不寫 `rm(list = ls())` | 它清掉的是別人的東西，不是你的問題來源 |

檢查自己有沒有踩到：

```bash
grep -n 'setwd\|rm(list' scripts/*.R    # 沒有輸出就是乾淨的
```

## 卡住了

| 症狀 | 做法 |
|---|---|
| 它報錯 | 把**整段錯誤訊息**貼回去，不要自己轉述 |
| 它動了 `raw/` | `git checkout raw/` 還原，然後告訴它 raw 唯讀 |
| 它給你選單而不是答案 | 在提示詞裡加一句「請直接用文字說明，不要給我選單」 |
| 你不知道它剛剛做了什麼 | 用 `PROMPTS.md` 附錄的 **P-救援 4** |
| 全部弄亂了 | `rm -rf scripts output figs docs`，從第 2 步重來。`raw/` 不會受影響 |

流程的驗收標準只有一條：**把 `output/` 和 `figs/` 整個刪掉，你能不能用三個指令長回來。**
長不回來，就表示流程有洞。

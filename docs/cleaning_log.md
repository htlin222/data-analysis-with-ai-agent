# 資料處理紀錄

> 用途：作為每項處理決定的書面依據。
> 每一條記錄原始狀態、處理方式、影響筆數、理由。

產生於 `scripts/01_clean.R`。原始資料在 `raw/cohort.csv`，唯讀。

---

## 1. age 缺失：不插補

| 項目 | 內容 |
|---|---|
| 原始狀態 | `age` 有 4 筆缺失（patient_id 47、73、80、91） |
| 處理方式 | 不插補，也不刪除個案。保留原樣 |
| 影響筆數 | Cox model 實際使用 **96 人 66 events**，而非 100 人 69 events |
| 理由 | 缺失僅 4%，且無從得知缺失機制。插補會引入假的精確度。**代價是模型會整列排除這 4 人，而且不會發出任何警告**——因此在 `03_survival.R` 中明確印出模型實際的 n 與 events |

## 2. stage_group：early vs advanced

| 項目 | 內容 |
|---|---|
| 原始狀態 | 四級分期 `I` / `II` / `III` / `IV` |
| 處理方式 | `I` / `II` → `early`；`III` / `IV` → `advanced` |
| 影響筆數 | early 49、advanced 51 |
| 理由 | **屬臨床判斷，非統計判斷。** 此處採用最常見的二分法。若 protocol 對 IIB、bulky disease 或 extranodal 另有定義，本條需重寫 |

## 3. age_group：60 歲切點

| 項目 | 內容 |
|---|---|
| 原始狀態 | 連續變項，範圍 31–81 歲 |
| 處理方式 | `>= 60` vs `< 60` |
| 影響筆數 | `<60` 58 人、`>=60` 38 人，另 4 人因 age 缺失無法分組 |
| 理由 | 供次族群分析使用。**切點為事後決定，該次族群分析因此屬探索性**，不作為結論依據 |

## 4. 類別變項轉 factor

| 項目 | 內容 |
|---|---|
| 處理方式 | `treatment`、`sex`、`stage` 轉為 factor，levels 明確指定 |
| 影響筆數 | 100 筆 |
| 理由 | 字串預設為字典序。`I, II, III, IV` 恰好正確，但同類編碼（如 `IX`）會排錯。明確指定 levels 為唯一可靠的做法。`sex` 同時轉為中文標籤，供 Table 1 呈現 |

## 沒有做的處理

- **未排除任何個案。** `time` 全為正、`status` 僅 0/1，無排除依據。
- **未插補。** 理由見第 1 條。
- **未修改 `raw/`。** 原始 CSV 的權限為 `r--r--r--`。
